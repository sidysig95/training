Ouvrir index.html pour une utilisation locale. Pour GitHub Pages, choisir Settings > Pages > Deploy from a branch > main > / (root).

Sauvegarde dans le navigateur, export/import JSON, suivi des charges, répétitions et mensurations. Les données personnelles ne sont pas envoyées à GitHub.
